# COMPILER_GROUP_FOUR — MiniLang Compiler

A complete, five-phase compiler for **MiniLang**, a small statically-typed language with
functions, recursion, `int`/`bool`, loops and conditionals. Written in **Java 17** with no
third-party dependencies.

```
 source.mini
     │
     ▼  Phase 1  Scanner            tokens
     ▼  Phase 2  Parser             AST
     ▼  Phase 3  Semantic + IR      type-checked AST  →  three-address code (IR)
     ▼  Phase 5  Optimizer          optimized IR
     ▼  Phase 4  Code generator     stack-machine bytecode
     ▼           Virtual machine    program output
```

## Quick start

Requirements: **JDK 17 or newer**. That is all — no Maven or internet needed for the scripts.

```bash
./scripts/build.sh                      # compile
./scripts/test.sh                       # run all tests (add: scanner|parser|semantic|ir|codegen|optimizer|examples)
./scripts/minic.sh examples/countdown.mini        # compile AND run a program
./scripts/minic.sh -O examples/countdown.mini     # ... with the optimizer
./scripts/demo.sh                       # every phase on one program (for the Phase 5 demo/recording)
```

Maven is also supported (`mvn package` builds `target/minic.jar` and runs the tests):

```bash
java -jar target/minic.jar -O examples/countdown.mini
```

## Command-line options

| Option | Effect |
|---|---|
| `--tokens` | Phase 1 – print the token stream |
| `--ast` | Phase 2 – print the abstract syntax tree |
| `--ir` | Phase 3 – print three-address IR (optimized if `-O`) |
| `--asm` | Phase 4 – print the generated bytecode |
| `--run` | compile and execute (default) |
| `-O` | Phase 5 – enable the optimizer |
| `--stats` | print optimizer statistics / VM instruction count to stderr |

Exit codes: `0` ok, `1` compile error, `2` runtime error, `64` bad usage.

## A MiniLang program

```
func fact(int n) : int {
    if (n <= 1) { return 1; }
    return n * fact(n - 1);
}

func main() : void {
    for (int i = 1; i <= 5; i = i + 1) {
        print("fact(", i, ") = ", fact(i));
    }
}
```

## Repository layout

```
src/main/java/compiler/
  scanner/     Phase 1   MiniScanner, Token, TokenType
  parser/      Phase 2   Parser, Ast, AstPrinter
  semantic/    Phase 3a  SemanticAnalyzer, Type, SemanticInfo
  ir/          Phase 3b  IrGenerator, Instr, Operand, IrProgram
  codegen/     Phase 4   CodeGenerator, VirtualMachine, OpCode, BcProgram
  optimizer/   Phase 5   Optimizer
  util/                  Diagnostic, CompilationFailed
  Driver.java            wires the phases together (used by Main and the tests)
  Main.java              command-line interface
src/test/java/compiler/tests/   one test suite per phase + end-to-end example tests
examples/                       sample programs; examples/expected/*.out = expected output; examples/errors/ = programs that must be rejected
docs/                           language spec, architecture, per-phase work plans, team workflow
scripts/                        build / test / run / demo helpers
```
